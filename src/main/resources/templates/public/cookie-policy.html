Cookies, on your terms.

A plain-language guide to browser storage used by this airline demonstration.

CategoriesNecessaryPreferencesAnalyticsMarketing
Current implementation

The platform uses a session cookie for sign-in and local browser storage for the consent decision. It does not currently load advertising or analytics trackers.

Always on

Necessary storage

The application session supports secure sign-in, CSRF protection and booking workflows. aerovistaCookieConsent remembers the categories you chose so the banner does not appear on every page.

Optional

Preferences

This category is reserved for interface, language and travel-preference choices. Selecting it records consent only; the current demonstration does not install an additional preference cookie.

Optional

Analytics

Reserved for anonymous service-performance measurement in a future deployment. No analytics script is loaded by this version.

Optional

Marketing

Reserved for tailored fare offers in a future deployment. Newsletter subscription is simulated in the browser and is not sent to a marketing provider.

Control

Change or withdraw consent

Select “Cookie settings” in the footer at any time. Saving new choices replaces the previous local consent record. Clearing site data in your browser also removes it.
